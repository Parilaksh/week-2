# 📚 Book Catalog App (React)

## 🚀 Overview

This is a simple **Book Catalog Application** built using **React**.
It displays a list of books and allows users to view detailed information about each book using routing.

---

## 🛠️ Tech Stack

* React.js
* React Router DOM
* JavaScript (ES6)
* CSS

---

## 📂 Project Structure

```
book-catalog/
│── src/
│   ├── components/
│   │   ├── BookList.js
│   │   ├── BookDetail.js
│   ├── data/
│   │   ├── books.js
│   ├── App.js
│   ├── App.css
│── public/
│── package.json
```

---

## ✨ Features

* 📖 Display list of books
* 🔗 Clickable "Read More" button
* 📄 Detailed book view
* 🔄 Dynamic routing using React Router
* 🎨 Clean and responsive UI

---

## ⚙️ Installation & Setup

### 1. Clone Repository

```
git clone https://github.com/your-username/book-catalog.git
```

### 2. Navigate to Project

```
cd book-catalog
```

### 3. Install Dependencies

```
npm install
```

### 4. Run the App

```
npm start
```

---

## 🌐 Routing

* `/` → Book List Page
* `/books/:id` → Book Detail Page
